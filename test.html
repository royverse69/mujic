03 / NEON HIGHLIGHT

A hard-shadow sticker. Never a blurry glow.

In Neon Highlight mode, the active lyric line snaps into a solid accent badge with high-contrast ink, heavy 700 weight, a 2px border, a 4px hard offset shadow, and a 1-degree tilt. Choose a preset swatch below or let Dynamic (Artwork) pull the pigment straight from your cover art.

RUN LOCALLY IN SECONDS

No build step required.

Clone the repository and serve the static files with any local HTTP server. Installable as a PWA straight from your browser. 

git clone https://github.com/royverse69/mujic.git
cd mujic
python -m http.server 3000
