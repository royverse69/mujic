Playback Effects

Soft track transitions
Brief fade between tracks instead of an abrupt switch; does not overlap audio.
Loudness control
Use a lightweight compressor to reduce large volume swings. Requires browser Web Audio support.
Loudness profile
Choose how gently or strongly volume peaks are controlled.
Advanced playback
Skip long silence
Move ahead after sustained near-silence during playback.
Instantly skip silence
Use a shorter silence threshold and a slightly larger skip. Applies only when Skip long silence is enabled.
Auto-skip unsupported tracks
Continue to the next queued track if this browser cannot decode a file.
Prevent duplicate queue items
Do not enqueue a track that is already in Up Next.
Preserve pitch
Keep voices closer to their original pitch when changing playback speed, where supported.
Varispeed
When enabled, pitch follows playback speed (tape-style speed changes). Overrides pitch preservation.
Progressive seek
Repeated media-session seeks made quickly add 5 seconds per press, up to a bounded limit.
Pause when muted
Pause playback when you mute the player or set volume to zero.
Stop on page exit
Pause playback when this page is unloaded. Browser/OS task-swipe events are not exposed reliably to PWAs.
Keep screen awake
Request a screen wake lock while the full player is open. Browser support varies.
Seek increment
Default jump used by lock-screen / media-session seek controls.
Hardware audio offload
Managed by the browser and operating system. A web/PWA app cannot safely force native hardware offload.

Lyrics Providers

Community lyrics server
Sends the song title and artist to a third-party server (onrender.com) when LRCLIB has no match. Turn off to keep lookups to LRCLIB only.
LyricsPlus fallback
Try the LyricsPlus synchronized-lyrics API only after embedded lyrics, cache, LRCLIB and the Render fallback. Requires an internet connection.
AI Song Identification
Experimental song identification is not available in this release.

About Mujic

Mujic was created by Ashutosh Roy (Machhar) out of curiosity and the need for a simple, lightweight player for music already on your device. There are many music apps, some with more features, but this one is special because it grew from a personal need. Thanks for being part of the journey. If you enjoy Mujic, please consider starring the open-source project on GitHub.
