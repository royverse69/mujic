# Mujic v13.5.0 — UI polish patch

- Added the animated Diwali wordmark to the desktop brand header and mobile Home watermark.
- Rebuilt the animation as a lightweight transparent WebP asset (72-frame transparent loop) and added it to the app-shell precache.
- Quick Picks now has a working refresh control and a next control that scrolls, appends the next loaded batch, or fetches a fresh batch when the current feed is exhausted.
- Removed decorative eyebrow labels, saved-count filler, and redundant helper copy from the Search start screen.
- Separated desktop mini-player volume/PiP tools with a distinct hit area; clicking the volume slider or dock padding no longer opens the full-screen player.
- Kept the large text watermark on desktop unchanged.
